# Kutubxona — Мобильное приложение «Цифровая библиотека»

**Kutubxona** — это мобильное приложение, разработанное в качестве курсовой работы. Оно представляет собой платформу для цифровой библиотеки, где пользователи могут находить, читать и слушать книги, а администраторы — управлять контентом.

Этот проект демонстрирует ключевые навыки разработки под Android, включая управление локальными базами данных, работу со сложными макетами интерфейса и модернизацию устаревшего кода.

## 🚀 Основные возможности

### Для пользователей:
*   **Авторизация:** Надежная система входа и регистрации с управлением профилем.
*   **Поиск и навигация:** Просмотр книг по категориям в чистом и организованном интерфейсе.
*   **Чтение:** Встроенный просмотрщик PDF для чтения электронных книг прямо в приложении.
*   **Аудиокниги:** Встроенный плеер для прослушивания аудиоверсий книг.
*   **Персонализация:** Функция «Закладки» для отслеживания прогресса (В планах, Читаю, Прочитано).

### Для администраторов:
*   **Управление контентом (CRUD):** Добавление, обновление и удаление книг, категорий и элементов дизайна.
*   **Управление пользователями:** Просмотр списка зарегистрированных пользователей.
*   **Работа с данными:** Синхронизация в реальном времени с локальной базой данных SQLite.

## 🛠 Технологический стек

*   **Язык программирования:** Java
*   **Интерфейс (UI/UX):** XML, Material Design Components, ViewBinding.
*   **База данных:** SQLite (реализована через `SQLiteOpenHelper` с кастомной логикой запросов).
*   **Хранение данных:** `SharedPreferences` для управления сессиями пользователей.
*   **Архитектура:** Навигация на основе фрагментов (Fragment-based navigation).
*   **Сборка:** Gradle (Обновлен до актуальных версий для поддержки современной Android Studio).

## 📈 Технические особенности реализации

*   **Миграция устаревшего кода:** Проект успешно перенесен из старой версии Android Studio в современную среду. Исправлены конфликты зависимостей, обновлена система сборки Gradle для поддержки **Java 21** и **Target SDK 34**.
*   **Оптимизация БД:** Реализована надежная работа с SQLite для обеспечения целостности данных между несколькими таблицами (Пользователи, Книги, Категории, Закладки).
*   **Улучшение UX:** Оптимизирована верстка для лучшей поддержки RTL (правостороннего письма) и специальных возможностей (использование единиц SP/DP).

## ⚙️ Установка и запуск

1.  Клонируйте репозиторий:
    ```sh
    git clone https://github.com/vash-login/kutubxona.git
    ```
2.  Откройте проект в **Android Studio (версия Hedgehog или новее)**.
3.  Выполните синхронизацию проекта с файлами Gradle (Sync Project with Gradle Files).
4.  Запустите приложение на эмуляторе или реальном устройстве (API 24+).
